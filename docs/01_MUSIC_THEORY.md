# 01 · 乐理推导 Music-Theory Derivation

本文从"为什么"出发推导 Giant Steps 的和声，每一步都给出可计算的形式，便于在代码和互动网页里复用（对应实现见 `music/gs/theory.py`）。

记号约定：音级（pitch class, pc）用整数 0–11 表示，`C=0, C♯/D♭=1, D=2, E♭=3, E=4, F=5, F♯=6, G=7, A♭=8, A=9, B♭=10, B=11`。所有音级运算都在模 12 下进行。

---

## 1. 曲子本身

- 录音：1959 年 5 月，纽约 Atlantic 录音室；1960 年初随同名专辑发行。
- 阵容：John Coltrane（次中音萨克斯）、Tommy Flanagan（钢琴）、Paul Chambers（贝斯）、Art Taylor（鼓）。
- 速度：约 286 BPM（常被引用的数值，大约每秒 4.8 拍）。
- 曲式：16 小节一遍（chorus），反复即兴。

### 1.1 和弦进行（16 小节，每小节 4 拍）

```
| Bmaj7   D7    | Gmaj7   B♭7   | E♭maj7        | Am7     D7    |
| Gmaj7   B♭7   | E♭maj7  F♯7   | Bmaj7         | Fm7     B♭7   |
| E♭maj7        | Am7     D7    | Gmaj7         | C♯m7    F♯7   |
| Bmaj7         | Fm7     B♭7   | E♭maj7        | C♯m7    F♯7   |
```

共 26 个和弦，其中 18 个只占 2 拍。在 286 BPM 下，2 拍 ≈ 0.42 秒 —— 每 0.42 秒，和声可能已经换到另一个调。

> 版权说明：和弦进行不受版权保护，旋律受保护。本项目**不演奏原曲主旋律、不使用原录音**，只使用和弦进行与原创（程序生成）的即兴和伴奏。

## 2. 参照系：普通爵士和声为什么"近"

### 2.1 五度圈

把音级乘以 7（模 12），得到它在五度圈上的位置：

```
fifths_index(pc) = (pc * 7) mod 12
C0 G1 D2 A3 E4 B5 F♯6 D♭7 A♭8 E♭9 B♭10 F11
```

五度圈上相邻的两个调只差一个升降号，大调音阶 7 个音里有 6 个相同。一般地，**相距 n 步（n ≤ 6）的两个大调，共有 7 − n 个共同音**（n = 1…4 时成立；n=5,6 时为 2 个）。

### 2.2 ii–V–I：沿五度圈"回家"

以 C 大调为例：`Dm7 → G7 → Cmaj7`，根音 D → G → C，每步都是纯四度上行（= 五度圈逆时针一步）。耳朵每一步都只移动一点点，所以始终清楚"家"在哪。

标准曲的调性通常会停留 2–8 个小节，再移到五度圈上的邻居。

## 3. Coltrane 的问题：把八度三等分

八度有 12 个半音。要把它**平均**分成若干份，只有 12 的因数可选：

| 份数 | 每份半音数 | 音程 | 得到的对称结构 |
|---|---|---|---|
| 2 | 6 | 三全音 | 三全音替代的基础 |
| 3 | **4** | **大三度** | **增三和弦 → Giant Steps** |
| 4 | 3 | 小三度 | 减七和弦 |
| 6 | 2 | 全音 | 全音阶 |

取 3 份：每份 4 个半音 = 大三度。从 B（11）出发不断减 4：

```
11 → 7 → 3 → 11      即  B → G → E♭ → B
```

`{3, 7, 11}` 是一个增三和弦，也是 Z₁₂ 的子群 `{0, 4, 8}` 的一个陪集（整体平移 3）。三个主音**互相等距**：在半音圈上画出来，是一个等边三角形。

### 3.1 放回五度圈：仍是等边三角形 → 最远的三个调

```
fifths_index(B)=5, fifths_index(G)=1, fifths_index(E♭)=9
```

两两相差 4 步，在五度圈上**同样是等边三角形**。这有两个含义：

1. 三个调彼此相距 4 个五度，套用 2.1 的公式：每两个调的音阶只共享 7 − 4 = **3** 个音。
   - B 大调 {B C♯ D♯ E F♯ G♯ A♯} ∩ G 大调 {G A B C D E F♯} = {B, E, F♯}
   - G ∩ E♭ = {G, C, D}；E♭ ∩ B = {E♭(=D♯), G♯(=A♭), A♯(=B♭)}
2. 升降号：B 大调 5♯、G 大调 1♯、E♭ 大调 3♭ —— 相邻两调相差 4 个升降号。

在 12 个调里，想选出三个"两两尽量远"的调，最优解正是在五度圈上等距的三个点。也就是说：**Coltrane 选择了三个彼此最陌生的调，却用了最对称的方式把它们连在一起。**

## 4. 引力：在每个调前面放属七和弦

直接从 Bmaj7 跳到 Gmaj7（只共享 3 个音阶音）会很突兀。解决办法：在目标调前插入它的属七和弦（V7），用最强的 V→I 引力把耳朵"接住"。

| 目标调 | 属七 | 属七根音 pc |
|---|---|---|
| G (7) | D7 | 2 |
| E♭ (3) | B♭7 | 10 |
| B (11) | F♯7 | 6 |

三个属和弦的根音 `{2, 6, 10}` 本身也是一个增三和弦（= 主音集合整体移动 −5，即下行纯四度）。

### 4.1 每一步的根音运动

```
Bmaj7 → D7 → Gmaj7
 11  +3→ 2 +5→ 7
```

小三度上行（+3）+ 纯四度上行（+5）= +8 ≡ −4，即**净效果是大三度下行**。前 7 小节就是把这个"+3、+5"的小单元重复三次，绕增三和弦转一圈。

### 4.2 "Coltrane changes"的定义（用于代码）

> 给定一组等距主音 `T = {t, t−4, t−8}`，在每个主音前插入其属七 `V(t) = t + 7`（可选再在前面插入 ii：`t + 2`），按大三度下行（或上行）依次连接。

## 5. 16 小节的两半：方向反转

### 5.1 前半（第 1–7 小节）：下行旋转，节奏密集

```
B → (D7) → G → (B♭7) → E♭ ‖ (Am7 D7) → G → (B♭7) → E♭ → (F♯7) → B
```

主音下行大三度，每个调只停 2 拍（第 3、7 小节停 4 拍作为"落脚点"）。

### 5.2 后半（第 8–16 小节）：ii–V–I，上行攀升

```
(Fm7 B♭7) → E♭ → (Am7 D7) → G → (C♯m7 F♯7) → B → (Fm7 B♭7) → E♭ → (C♯m7 F♯7) → [回到第1小节 B]
```

每个调都由完整的 ii–V 进入，主音以大三度**上行**：E♭ → G → B → E♭，每个调停一整小节。最后的 C♯m7 F♯7 是回到开头 Bmaj7 的转回（turnaround）。

### 5.3 调性中心表（每个和弦属于哪颗"星"）

| 小节 | 和弦 | 功能 | 所属调 |
|---|---|---|---|
| 1 | Bmaj7 / D7 | I / V7 | B / G |
| 2 | Gmaj7 / B♭7 | I / V7 | G / E♭ |
| 3 | E♭maj7 | I | E♭ |
| 4 | Am7 / D7 | ii / V7 | G |
| 5 | Gmaj7 / B♭7 | I / V7 | G / E♭ |
| 6 | E♭maj7 / F♯7 | I / V7 | E♭ / B |
| 7 | Bmaj7 | I | B |
| 8 | Fm7 / B♭7 | ii / V7 | E♭ |
| 9 | E♭maj7 | I | E♭ |
| 10 | Am7 / D7 | ii / V7 | G |
| 11 | Gmaj7 | I | G |
| 12 | C♯m7 / F♯7 | ii / V7 | B |
| 13 | Bmaj7 | I | B |
| 14 | Fm7 / B♭7 | ii / V7 | E♭ |
| 15 | E♭maj7 | I | E♭ |
| 16 | C♯m7 / F♯7 | ii / V7 | B |

这张表（以及每个和弦的和弦音）由 `theory.py` 计算并写入 `data/giant_steps.json`。

## 6. 历史上下文（谨慎陈述）

- **先例**：Rodgers & Hart 的 *Have You Met Miss Jones?*（1937）桥段中，调性按大三度移动（B♭ → G♭ → D），常被认为是 Coltrane 的灵感来源之一。
- Coltrane 研究过 Nicolas Slonimsky 的 *Thesaurus of Scales and Melodic Patterns*（1947），书中大量使用把八度等分的对称音型 —— 这是常见说法，具体影响程度难以考证。
- **延伸**：同专辑的 *Countdown*（基于 *Tune Up* 的重配和声）、*26-2*（基于 *Confirmation*），以及 *Satellite*、1960 年的 *Body and Soul* 等，都把这种"三主音循环"嫁接到标准曲上。
- 录音中钢琴手 Tommy Flanagan 的独奏非常稀疏，这常被用来说明这套和声在当时有多难。

## 7. 即兴的乐理工具（视频 S6 与即兴引擎的依据）

| 工具 | 定义 | 例（Bmaj7） | 例（D7） |
|---|---|---|---|
| 1-2-3-5 | 根、二、三、五级，4 个八分音符 = 2 拍 | B C♯ D♯ F♯ | D E F♯ A |
| 5-3-2-1 | 下行版本 | F♯ D♯ C♯ B | A F♯ E D |
| 和弦琶音 3-5-7-9 | 从三音开始的琶音 | D♯ F♯ A♯ C♯ | F♯ A C E |
| 导音线 guide tones | 只走三音与七音，最小移动连接 | D♯(3) → C(7 of D7)… | |
| 半音接近 approach | 用半音从上/下进入下一个和弦的目标音 | → | |
| 包围 enclosure | 目标音上方一音 + 下方半音 → 目标 | | |

导音线示例（前 3 小节，两个声部，每个和弦取三音与七音，按最小移动配对；由 `theory.guide_tone_lines()` 计算）：

```
           Bmaj7   D7    Gmaj7   B♭7   E♭maj7
声部 A:     D♯(3) → F♯(3) → F♯(7) → A♭(7) → G(3)
声部 B:     A♯(7) → C(7)  → B(3)  → D(3)  → D(7)
```

每一步只移动 0–3 个半音，而且三音与七音会互相"交棒"（A 声部的 F♯ 从 D7 的三音变成 Gmaj7 的七音）。

这正是在快速换调中"保持旋律连贯"的秘诀：**和弦跳得很远，但三音和七音之间几乎只差半音或全音。**
