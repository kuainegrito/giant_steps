# 02 · 视觉与声音设计 Design Decisions

## 1. 设计目标

1. **唯美，但不装饰过度**：深夜星空的底色，所有元素都是"光"——发光的点、线、音符。没有花哨的转场，靠颜色、呼吸般的亮度变化和缓慢的运动营造氛围。
2. **每一个画面元素都承载乐理信息**：颜色 = 调性，位置 = 音级，亮度 = 当下正在发生。观众即使关掉声音，也能从画面里读出结构。
3. **一个核心意象贯穿全片**：十二个音组成的圆 + 三颗星（B、G、E♭）组成的等边三角形。

## 2. 颜色系统

| 角色 | 颜色 | 用途 |
|---|---|---|
| B 调 | `#7fd3ff` 冰蓝 | B 大调及通往它的 F♯7、C♯m7 |
| G 调 | `#f5c46b` 琥珀金 | G 大调及 D7、Am7 |
| E♭ 调 | `#f07aa0` 玫瑰红 | E♭ 大调及 B♭7、Fm7 |
| C 调（对照组） | `#d9dcea` 中性白 | S2 的普通 ii–V–I 示例 |
| 墨色 | `#f3efe6` | 文字（暖白，避免纯白刺眼） |
| 背景 | `#04060d → #0c0f24` 渐变 | 夜空 |

**属和弦与 ii 和弦继承它们所指向的调的颜色**（数据里每个和弦都有 `key` 字段）。所以当和声在快速移动时，画面上的颜色变化正好就是"调性中心的跳跃"，而不是和弦根音的跳跃 —— 这是本片最重要的一个设计决定：让眼睛看见"三颗星"，而不是 26 个和弦。

背景里有三团对应三种颜色的星云，亮度跟随当前调性（对最近 1.5 秒的和弦做加权），音乐在哪个调，整个天空就微微染上那个颜色。

## 3. 字体

| 用途 | 字体 | 原因 |
|---|---|---|
| 中文 | Noto Serif CJK SC（思源宋体） | 宋体的笔画对比与"唯美"基调一致；开源 OFL |
| 英文、和弦名、数字 | Cormorant Garamond（斜体为主） | 高对比度的 Garamond 风格，和宋体气质一致；开源 OFL |
| ♭ ♯ ∩ | DejaVu Serif（只用这几个字符，`unicode-range`） | 前两种字体里的升降号太宽，"E ♭" 会断开 |

## 4. 核心图形：音级圆

- 12 个节点，C 在正上方。
- 参数 `m ∈ [0,1]` 在**半音圈（m=0）**与**五度圈（m=1）**之间连续变形：每个节点的角度在两种排列之间沿最短方向插值。
- 关键时刻（S3 L14）：三角形在半音圈上是等边的，圆变形为五度圈后，三角形**仍然是等边的**——变形动画让观众亲眼看到这一点，比任何文字都有说服力。
- 圆的位置、大小、透明度、m、旋转由一组关键帧控制（`circleState(t)`），在场景之间平滑过渡，所以它是贯穿全片的"同一个物体"。

## 5. 各场景的视觉方案

| 场景 | 主要元素 | 同步点 |
|---|---|---|
| S0 序 | 星空、标题字距由宽收紧；三颗星的暗示 | 片头 |
| S1 背景 | 三张数字卡片（286 BPM / 0.42 秒 / 3 个调） | L03 每个分句出现一张 |
| S2 五度圈 | 节点按五度顺序逐个点亮；Dm7→G7→Cmaj7 箭头；"家"；相邻调的弧 | L07 的 "D 小七 / G 七 / C 大七" 分句 |

## 6. 声音设计

- **不使用原录音、不演奏原曲主旋律**（版权）。
- 音色：GeneralUser GS（免费 SoundFont）。次中音萨克斯（GM 66）、原声钢琴、原声贝斯、GS Jazz 鼓组；讲解段用电钢琴（Rhodes 类）+ 温暖 Pad + 颤音琴。
- 讲解背景里的和弦**落在念到它的那个分句上**（例如念"到 G"时 Gmaj7 响起），由时间轴按分句时间生成。
- 混音：讲解时背景音乐自动压低 7 dB（250 ms 平滑）；成片响度标准化到 −16 LUFS。

## 7. 为什么用浏览器 Canvas 而不是视频软件

- 渲染函数 `render(t)` 是纯函数：同一个 t 永远画出同一帧，可以多进程并行渲染、可以任意跳到某一帧检查。
- 网页版只需要把 `t` 换成 `audio.currentTime`，再加上交互控件（见 06_WEB_ROADMAP）。
- 所有画面都由 `data/timeline.json` 驱动，改讲稿 → 重新生成配音 → 时间轴自动重排 → 画面自动对齐。

## 8. 已知取舍

| 取舍 | 原因 |
|---|---|
| 配音为离线 TTS（MeloTTS），不如真人自然 | 运行环境无法访问在线语音服务；讲稿与配音解耦，以后可直接替换为真人录音（只需替换 `build/tts/*.wav` 并重跑时间轴） |
| 合成萨克斯音色有限 | 重点在于"听清结构"；网页版可换更好的音色库 |
| 即兴为规则生成，不是机器学习模型 | 规则透明、可解释，每个音都能说出"为什么" —— 这正是教学需要的 |
