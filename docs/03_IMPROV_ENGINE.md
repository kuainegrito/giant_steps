# 03 · 即兴生成引擎 Improvisation Engine

实现：`music/gs/improv.py`。目标不是"像 Coltrane"，而是**按照老师教学生练这首曲子的方式生成一条可解释的旋律线**，每个音都带着"为什么选它"的标签。

## 1. 输入与输出

```python
improvise(chords, n_choruses, style=SLOW | FAST, seed=1959) -> [note, ...]
```

每个音：

```json
{"t": 6.62, "grid": 6.5, "d": 0.35, "p": 65, "v": 91,
 "chord": 3, "chorus": 0, "phrase": 2,
 "cell": "3579", "degree": "5", "role": "chord"}
```

| 字段 | 含义 |
|---|---|
| `t` / `grid` | 实际时间（含摇摆与人性化偏移）/ 网格位置，单位：拍 |
| `cell` | 来自哪个音型：`1235`、`3579`、`35b7b9`、`scale`、`guide`、`landing`、`approach`、`enclosure`、`pickup`… |
| `degree` | 相对当前和弦的度数：`1 9 3 5 7 b9 #11 b13`… |
| `role` | `chord` 和弦音 / `tension` 延伸音 / `scale` 音阶音 / `approach` `enclosure` 半音接近 / `chromatic` |

## 2. 算法

### 2.1 词汇：四音音型（cells）

| 和弦 | 音型（相对根音的半音数） |
|---|---|
| maj7 | 1235 `[0,2,4,7]`、5321、3579 `[4,7,11,14]`、1357、7531、9753、3217 |
| 7 | 1235、3579 `[4,7,10,14]`、35b7b9 `[4,7,10,13]`、b9b753、5321、8b753 |
| m7 | 1235 `[0,2,3,7]`、b35b79、1b35b7、5b321、b75b31 |

4 个八分音符 = 2 拍 = Giant Steps 里最常见的和弦时值，这正是 1-2-3-5 在这首曲子上特别好用的原因。

### 2.2 选择：声部进行打分

对每个和弦片段，枚举「音型 × 八度」的所有候选（限制在 D3–G5 之间），计算代价：

```
cost = leap(第一个音 − 上一个音)      # 1–3 个半音代价为 0；同音 2.5；更大的跳进线性增加
     + 0.04 × |候选平均音高 − 65|      # 留在中音区
     + 0.6 × [与上一个音型相同]          # 鼓励变化
```

然后用 softmax（温度 1/1.6）按代价随机挑选 —— 既倾向平滑，又不机械。4 拍的和弦有 30% 概率改用 8 个音的音阶跑句（`scale`），碰到音域边界会自动折返。

### 2.3 连接：半音接近与包围

生成完一条线后再做一遍后处理：在每个换和弦的位置（前一个八分音符属于上一个和弦）：

- 以 `enclosure_prob` 的概率把最后两个音改成"上方半音 → 下方半音 → 目标音"（包围）；
- 否则以 `approach_prob` 的概率把最后一个音改成目标音的上方或下方半音（如果会造成同音重复，就换另一侧）。

这一步让旋律"提前听见"下一个调——这是在快速换调中保持连贯的关键。

### 2.4 乐句

- 状态机：`rest`（呼吸）↔ `phrase`（演奏）。乐句长度、休止长度按合奏遍数从 `Style` 里抽取，后面的遍数更长、更密。
- 乐句结尾：最后一个和弦片段只演奏 2–4 个八分音符，然后落在一个长音上（`landing`，优先选 3、7、9 等"有颜色"的音）。
- 乐句开头：有一定概率加两个八分音符的弱起（`pickup`）。
- 慢速第一遍里，有 35% 的片段只演奏一个导音（`guide`：最接近上一个音的三音或七音）——先建立和声骨架，再逐渐加密。

### 2.5 演奏感

- 摇摆：反拍八分音符推迟到 `swing`（慢速 0.62、快速 0.56）处。
- 力度：基础 80，音越高越强，反拍重音 +7，乐句第一个音 −6，长音 +4，再加 ±5 随机。
- 时值：正拍音持续到摇摆点的 92%，形成连奏。

## 3. 两种风格

| 参数 | SLOW（140 BPM，2 遍） | FAST（286 BPM，4 遍） |
|---|---|---|
| swing | 0.62 | 0.56 |
| 导音概率（各遍） | 0.35, 0.10 | 0.12, 0.05, 0, 0 |
| 乐句长度（拍） | 6–10 → 8–16 | 8–12 → 16–24 |
| 休止（拍） | 2–4 → 1–3 | 2–3 → 1–2 |
| 半音接近 / 包围 | 0.45 / 0.20 | 0.50 / 0.25 |

## 4. 示范片段

- `demo_1235`：前 3 小节每个和弦一组 1-2-3-5（E♭maj7 四拍时上行接下行）。
- `demo_guide`：前 3 小节的两声部导音线（三音/七音），由 `theory.guide_tone_lines()` 用最小移动配对。

## 5. 可复现性与网页移植

- 所有随机性来自 `random.Random(seed)`；同一个 seed 永远得到同一段即兴。视频用的是 `seed=1959`（慢速）和 `1966`（快速）。
- 算法只依赖 `data/giant_steps.json` 里的和弦数据，移植到 JS 时：音型表、打分函数、后处理三部分各自独立，约 200 行。网页可以提供"换一个 seed"、"调节密度/半音接近概率"、"只看导音"等控件，并在每个音上显示 `cell / degree / role`。

## 6. 已知局限

- 没有动机发展（重复并变化一个短动机），也没有三连音、装饰音。
- 不会"听"伴奏：钢琴与即兴各自生成，只共享和弦。
- 节奏只有八分音符、长音与休止三种。

这些都是下一版（网页）可以逐步加入的方向。
