# 06 · 互动网页路线图 Interactive Web Roadmap

视频是"讲给你听"，网页是"让你自己动手"。网页直接复用本仓库的数据与渲染代码。

## 已经可以复用的部分

| 资产 | 位置 | 网页里的用途 |
|---|---|---|
| 和弦/调性/导音数据 | `data/giant_steps.json` | 所有组件的乐理来源 |
| 演奏数据 | `data/performances/*.json` | 播放、可视化、逐音解释 |
| 渲染器 | `web/js/render.js`（纯函数 `render(t)`） | 视频同款画面；已有 `web/preview.html` 可拖动时间轴预览 |
| 组件 | 音级圆（半音/五度可变形）、16 小节格、键盘、钢琴卷帘 | 拆成独立组件 |
| 音色 | GeneralUser GS + `spessasynth_lib`（浏览器版） | 与视频同一音色 |

## 建议的功能（按优先级）

1. **可交互的音级圆**：拖动滑块在半音圈 ↔ 五度圈之间变形；点击任意一个音，自动画出它的"三等分三角形"（任何音都能作为起点，共 4 组增三和弦）。
2. **16 小节播放器**：播放乐队伴奏，可调速度（60–300 BPM）、单独开关贝斯/钢琴/鼓；当前和弦与调性实时高亮。
3. **即兴生成器**（`improv.py` 的 JS 版）：换 seed、调密度、调半音接近概率、只用 1-2-3-5、只用导音……每个音悬停显示 `cell / degree / role`。
4. **练习模式**：屏幕键盘或 MIDI 键盘输入，实时判断你弹的音是和弦音、延伸音还是经过音（用同一套 `degree_label` 规则）。
5. **"Coltrane 化"任意进行**：输入一个 ii–V–I，自动生成 Coltrane substitution（对应 01 文档 4.2 节的定义），并可视化。
6. **中英双语界面**：文案直接取自 `docs/01_MUSIC_THEORY.md` 与 `data/script.json`。

## 技术建议

- 纯静态站点（无需后端），可部署到 `/giant-steps/` 之类的子路径。
- 模块：`theory.js`（已有）、`render.js`（拆分组件）、`improv.js`（待移植）、`audio.js`（spessasynth_lib 包装）。
- SoundFont 约 30 MB，可换成 SF3（压缩版）或只抽取用到的几个音色，以减小首屏加载。
