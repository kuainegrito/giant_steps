# Giant Steps · 三颗星的轨道

用代码讲解 John Coltrane《Giant Steps》（1959）背后的和声逻辑 —— **把八度三等分的 Coltrane changes** —— 并生成一段即兴演示。

本仓库包含：讲解视频的完整生成流水线、乐理推导、设计决策，以及可直接被互动网页复用的 JSON 数据与渲染代码。

> 本项目不使用原录音，也不演奏原曲主旋律；只使用和弦进行（不受版权保护）以及程序生成的原创即兴与伴奏。
